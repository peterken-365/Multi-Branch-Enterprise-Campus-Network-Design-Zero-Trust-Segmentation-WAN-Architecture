04 · Zero trust

Zero-Trust Security Policy

A hardened management plane, a gateway ACL matrix that denies by default, and the Layer-2 attack mitigation suite at every access port. Denies are logged — ACL counters and the central Syslog server double as audit evidence.

Layer 2

The switch-security trio at the access layer

Rogue DHCP, ARP poisoning and MAC-spoofing hubs are stopped at the wall jack — exactly what verification tests T-05 and T-06 prove.

T-06 double enforcement: an unprivileged user in Guest VLAN 40 attempting SSH fails twice over — first GUEST-IN drops the packet at the guest gateway (it never routes), and even if a host somehow reached the device, MGMT-ACCESS on the VTY lines only accepts 10.20.10.0/26 sources, with the attempt visible in Syslog via deny any log.
