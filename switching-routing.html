Why native VLAN 999: a double-tagging (VLAN hopping) attempt lands the frame in the unrouted quarantine VLAN, where there are no hosts and no gateway. DTP is disabled (nonegotiate) so an attacker-controlled device cannot negotiate trunking with an access port.

Layer 3

OSPFv2 — single Area 0, passive by default

Why passive-interface default matters: an OSPF hello on a guest or finance LAN would let any laptop run area-0 tooling, become a rogue neighbor and inject routes. With passive-interface default, hellos exist only on the two transit /30s — and the guest VLAN is additionally ACL-blocked from speaking to any internal destination at all.

Build order

Reproduce the topology in six steps

Follow the Packet Tracer build guide for device placement, cabling and server services — then paste the configs in this order.

  1. MLS-HQ-CORE — VLANs, trunks, SVIs, gateway ACLs, STP root, OSPF. The core is the foundation everything else hangs off.
  2. SW1 + SW2 (HQ access) — VLANs, uplink trunks, access ports with the security trio, management SVIs.
  3. SW3 (branch access) — VLAN 50 access ports, uplink trunk to R2, branch management SVI.
  4. R1-HQ-EDGE — interfaces, NAT/PAT, EDGE-INBOUND, OSPF with default-information originate.
  5. R2-MOMBASA-EDGE — 802.1Q sub-interfaces, BRANCH-IN policy, DHCP relay, OSPF.
  6. On every device — crypto key generate rsa modulus 2048 in EXEC mode, then copy running-config startup-config.
