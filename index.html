Savannah Logistics Ltd. — multi-branch enterprise campus network

Nairobi HQ and the Mombasa branch on six Cisco devices in one OSPF domain. This site is the lab notebook: build files, device configs, policy tables, and the recorded CLI evidence behind every claim. Everything can be reproduced in Packet Tracer 8.2+ in under an hour.

How to read this site. Every claim is paired with the command that proves it and the config that implements it. The transcripts on these pages are reference outputs recorded from the golden configs in this repository; the verification runbook gives you the exact commands and pass criteria to reproduce them yourself. If you cannot run the lab, the console replay shows the recorded sessions — clearly labelled as a replay, not a live device.

The build

Two sites, six Cisco devices, one routed WAN, and a deny-by-default policy at every gateway. Built as a lab on Packet Tracer 8.2; the same configs target ISR 4331 and Catalyst 9200/9300 in production — lines Packet Tracer does not support are pre-commented as PRODUCTION-ONLY in each file.

Reproduce it yourself

  1. Read the Packet Tracer build guide — device placement, cabling table, server services. Estimated build time: 60–90 minutes.
  2. Cable per the link inventory (or section 2 of the guide).
  3. Paste configs in build order MLS → SW1 → SW2 → SW3 → R1 → R2 from 02-switching-and-routing-design/configs/, then run crypto key generate rsa modulus 2048 on every device (EXEC mode).
  4. Configure the four server services (DHCP scopes, NTP + Syslog on, DNS records, HTTP).
  5. Run the pre-flight checks P-1 … P-8.
  6. Run T-01 … T-07 in order and compare with the transcripts on the runbook page. Outputs may differ cosmetically between Packet Tracer and IOS-XE — the pass criteria are behavioral.

Want to see the expected outputs before building? The lab console replays the recorded CLI sessions per device — pick a device, type a command, compare.
